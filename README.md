# AI ERP

## Overview
A modular, AI-enabled Enterprise Resource
Planning system.

## Architecture
- Frontend: React + TypeScript
- Backend: Python + FastAPI
- Database: PostgreSQL
- ORM: SQLAlchemy
- Migrations: Alembic
- Cache: Redis
- Background jobs: Celery

## Development Principles
- Modular monolith architecture
- Separation of business logic and data access
- Secure authentication and authorization
- Testable and maintainable modules
- AI features with controlled access to ERP data
